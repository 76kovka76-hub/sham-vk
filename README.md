# SHAM — автономный бесплатный мем-бот ВКонтакте

**ВК:** https://vk.ru/club243230846 (ID `243230846`)  
**GitHub:** https://github.com/76kovka76-hub/sham-vk

> Версия без платного OpenAI API и без постоянно включённого компьютера. GitHub Actions запускается в **:08, :23, :38, :53 UTC**, до **96 попыток в сутки**. **4 изображения — фотореалистичные вымышленные лица, 92 — аниме**. Фактическое число успешных публикаций зависит от доступности бесплатной волонтёрской сети AI Horde и VK/ВедиSMM.

## Возможности

- Каждый успешный пост: авторская ситуация + смешной панчлайн на **генерируемом нейросетью** PNG 1080×1080 с текстом, короткая подпись и **ровно 3 хэштега**.
- Хэштеги выбираются по теме из словаря распространённых русскоязычных тегов. Внутри одного поста все 3 разные; тройка из предыдущих постов больше не используется. Одиночные теги не повторяются в последних 12 публикациях, когда это возможно. Бесконечного запаса *популярных* тегов нет: одиночные теги со временем будут возвращаться. Реальная текущая популярность тегов автоматически не проверяется.
- Множество вариаций мемов по шести темам: работа, деньги, телефон, дом, переписки, жизнь. Внутри темы комбинируются оригинальные завязки и подходящие панчлайны.
- Защита от точных повторов текста в `state/history.json`; SHA-256 идентификатор каждой шутки. После публикации бот фиксирует идентификатор временного слота и ID поста ВК.
- `wall.post` передаёт стабильный `guid` для уменьшения риска двойной отправки.
- Мем публикуется **только с прикреплённым фото**. При неудачной загрузке картинки отправка текста отменяется.
- Без платного API — Python, Pillow, GitHub Actions, AI Horde и ВедиSMM. Бесплатный AI Horde не гарантирует скорость и количество запросов: во время загрузки сети публикации пропускаются. При исчерпании банка мемов бот завершит запуск с ошибкой; банк примерно на 3500 комбинаций.

## Альтернативный бесплатный канал: ВедиSMM (экспериментально)

Если VK_USER_TOKEN получить не удалось, можно использовать VediSMM: https://vedismm.ru/. На ноябрь 2026 сервис **заявляет** бесплатное использование без лимита публикаций и предоставляет официальный REST API для загрузки файлов, создания записей и запуска публикации. **Это не гарантия успешной отправки картинок в VK**: ВКонтакте по-прежнему ограничивает метод photos.getWallUploadServer для ключей сообществ. Проверить путь можно только после подключения SHAM.

**Единовременная настройка владельцем** (после неё ПК можно выключить):
1. Зарегистрироваться в ВедиSMM и подключить сообщество VK **243230846**. Ключ сообщества вводить только на сайте сервиса, не в чате.
2. В личном кабинете ВедиSMM создать **персональный API-токен (PAT)** с правами `accounts:read`, `media:write`, `posts:write`, `posts:publish`, `jobs:read`. Не путать с VK_USER_TOKEN.
3. В GitHub Actions Secrets добавить `VEDISMM_TOKEN` со значением PAT: https://github.com/76kovka76-hub/sham-vk/settings/secrets/actions.
4. В GitHub Actions Variables добавить `SHAM_BACKEND` = `vedismm`: https://github.com/76kovka76-hub/sham-vk/settings/variables/actions.
5. При очередном запуске SHAM найдёт подключённую группу автоматически через `GET /accounts` по ID `243230846`. Если сервис не возвращает ожидаемый идентификатор, можно дополнительно задать переменную `VEDISMM_ACCOUNT_ID` (внутренний ID аккаунта внутри ВедиSMM, **не** номер VK-группы).

Далее GitHub Actions каждые 15 минут генерирует картинку, отправляет её в медиатеку ВедиSMM и создаёт пост с изображением. Бот проверяет отдельное задание публикации; только успех конкретной VK-цели считается подтверждённым размещением. Если через ~100 секунд статус всё ещё pending, запись фиксируется как **queued**, а не как опубликованная. Статусы и лимиты VK могут меняться. Начните с одного тестового запуска `Run workflow → publish` после настройки и проверьте вид поста в ВК.

При неудачной загрузке изображения текст отдельно не публикуется. Остановить публикацию: `SHAM_PAUSED=true`. Не включайте оба канала сразу: `SHAM_BACKEND` выбирает только один из них.

Источник по возможностям и API: https://vedismm.ru/docs/api

## Стили: 4 реалистичных + 92 аниме в сутки

- Запланировано 96 попыток: каждые 15 минут круглосуточно; GitHub не требует включённого домашнего компьютера.
- **Фотореализм** — первая четверть часа в 00:00, 06:00, 12:00 и 18:00 UTC (номинальный запуск GitHub в :08). Генерируется вымышленный взрослый человек с живыми эмоциями.
- **Аниме** — остальные 92 четверти часа: оригинальные персонажи с эмоциями и юмористической сценой.
- Генератор — **AI Horde** (https://aihorde.net/), бесплатная сеть волонтёров. По умолчанию используется анонимный API-ключ `0000000000`; **это самый низкий приоритет очереди**. Установка необязательного `AIHORDE_API_KEY` в GitHub Actions Secrets с бесплатной регистрацией на AI Horde улучшит приоритет, но тоже не гарантирует скорость.
- Openverse полностью исключён. Рисованный шаблон в старом стиле отключён; при ошибке нейрогенерации пост **не публикуется**.
- Очередь генерации ожидается до ~6 минут за запуск, поэтому 96 публикаций каждый день **не гарантированы**. 512×512 исходное нейроизображение адаптируется до итогового PNG 1080×1080, что не добавляет настоящей детализации. Для более высокого качества понадобится более мощный доступный генератор.
- Для изображений с вымышленными людьми нельзя считать изображение достоверным фото реального события или человека.
- AI Horde может использовать запросы/изображения для улучшения сервиса согласно своим условиям. Не отправляйте в генератор частные сведения или фото людей без согласия.
- Предпросмотр без отправки в ВК: GitHub Actions → Run workflow → preview. В артефакте `sham-preview-...` будут `sham_meme.png`, `preview.json`, `image_source.json`.

## Настройка доступа ВК

Для прямого способа VK (SHAM_BACKEND=vk) секреты задаются здесь: https://github.com/76kovka76-hub/sham-vk/settings/secrets/actions

Добавьте в **Repository secrets**:

- `VK_USER_TOKEN` — токен администратора для `photos.getWallUploadServer` и `photos.saveWallPhoto` с подходящими разрешениями.
- `VK_GROUP_TOKEN` — токен сообщества для `wall.post` (можно не задавать: тогда бот попробует использовать пользовательский токен).

**Никакие токены не присылайте в переписку и не записывайте в репозиторий.** Наличие секретов нельзя подтвердить чтением из GitHub; их права проверяются только выполнением задания. Права и авторизацию надо получать через официальные средства ВКонтакте.

Настройка переменных: https://github.com/76kovka76-hub/sham-vk/settings/variables/actions

В **Repository variables**:

| Name | Value |
|---|---|
| `SHAM_PAUSED` | `true` — экстренно остановить публикации; `false` или отсутствие — публикации разрешены |

Запуск SHAM разрешён в GitHub Actions по запросу владельца. Устаревшая переменная `PUBLISH_ENABLED` больше не используется в workflow (сам скрипт сохраняет дополнительный внутренний выключатель для локального запуска).

**Не нужен:** `OPENAI_API_KEY`. Переменных для платной генерации в этой версии нет.

## Как проверить без публикации

Откройте https://github.com/76kovka76-hub/sham-vk/actions, выберите workflow «SHAM — пост каждые 15 минут», **Run workflow** → **preview**.

После завершения скачайте артефакт `sham-preview-...` внизу страницы запуска. В нём будут `sham_meme.png` и `preview.json` (картинка, текст, подпись, все 3 хэштега).

Автоматические `push`-проверки кода также используют только безопасный preview.

## Как включить автопостинг

1. Добавить `VK_USER_TOKEN` (и при необходимости `VK_GROUP_TOKEN`) в GitHub Secrets.
2. Проверить **preview** и картинку.
3. В GitHub Actions проверьте автоматический запуск публикации: при первом успешном посте скрипт покажет ссылку на стену ВК.
4. Далее workflow запускается в :08, :23, :38, :53 каждого часа в UTC; часть запросов AI Horde может завершаться без изображения и без публикации.
5. Для ручного запуска можно выбрать **Run workflow → publish**.

Остановка: установите **Repository variable** `SHAM_PAUSED=true` или отключите workflow через GitHub Actions. Рабочий процесс проверяет паузу перед каждой отправкой.

**Риски:** GitHub Actions может задерживать или пропускать scheduled-запуски. В публичных репозиториях без активности 60 дней расписание может автоматически отключиться. ВК может ограничивать активную публикацию из-за flood control. 96 постов в день — **целевая частота, не гарантия**. Не рекомендуется искусственно обходить ограничения ВК. При ошибке API бот не публикует текст вместо картинки.
