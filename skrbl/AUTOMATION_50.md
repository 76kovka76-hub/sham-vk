# SKRBL: 50 оригинальных карандашных комиксов в сутки

**Состояние:** планировщик и VediSMM scheduler подготовлены; производство 50 детальных комиксов **ещё не автоматизировано**, автопубликация **отключена**. Не путайте подготовленный код с реальными 50 публикациями.

## Схема

- Группа: [SKRBL](https://vk.ru/club243241856), ID **243241856**, подключённая учётная запись VediSMM подтверждена в тесте.
- 50 уникальных слотов за 24 часа UTC. Интервалы чередуются по 28 и 29 минутам. Расписание хранится в `skrbl/queue_state.json`; логика в `skrbl/queue_planner.py`.
- Каждая публикация — **свой** 2–4-кадровый комикс, грубые карандашные линии, насыщенная сценка, абсурдная жёсткая шутка, матерные слова только с цензурой (например `бл***ь`), ровно три хэштега.
- Пропускать слоты при отсутствии качественной картинки, **никогда** не заменять простыми палочными человечками или аниме-портретами. Не переиспользовать опубликованные мемы.
- GitHub Actions `SKRBL — план 50 комиксов в сутки` умеет регулярно пополнять 12-часовую очередь ВедиSMM. Работает без домашнего компьютера, но сервер GitHub может задерживать запуски.
- Строго проверяется привязка к группе SKRBL перед публикацией. Записи SHAM бот не трогает.

## Что реализовано

1. `queue_planner.py`: 50 равномерных слотов в сутки, выбор следующего свободного слота и проверка разрешённого оригинального комикса.
2. `queue_publish.py`: загрузка изображения и отложенная публикация только в SKRBL через ВедиSMM с идемпотентным ключом.
3. `approved.json`: список рисунков, допущенных к публикации. Каждый обязан иметь `id`, `file` (PNG из `skrbl/approved/`), точный `sha256`, `caption` (ровно 3 хэштега), `panels` 2–4, `approved: true`.
4. `queue_state.json`: не допускать повторов по идентификатору и SHA-256; сохранять внутренний ID отложенной публикации.
5. `skrbl/tests/test_queue.py`: 6 тестов расписания, безопасности, цензуры и антидублирования.

## Что пока НЕ готово

Автоматическая генерация **ровно таких же детальных четырёхкадровых** карандашных комиксов, как одобренный пост о зарплате. ChatGPT image generation внутри чата нельзя просто вызвать из GitHub Actions. Бесплатная AI Horde не гарантирует читаемый русский текст, последовательность персонажей и стабильно высокое качество. Чтобы автоматически получать 50+ уникальных пригодных комиксов в сутки, требуется испытанный внешний image API с достаточной квотой, проверка качества и редакторская очередь.

Пустой `approved.json` сделан **намеренно**. Пока он пуст, публикации не выполняются.

## Как включить после подключения качественного генератора

- Наполнять `skrbl/approved/` **уникальными качественными** PNG и прописывать их SHA-256 в `approved.json`.
- Подготовить достаточный запас: для первых 12 часов приблизительно 25 комиксов, в дальнейшем не менее 50 новых ежедневно, плюс запас на отказы генератора.
- Добавить `SKRBL_ENABLE_AUTOPUBLISH=true` в **GitHub Actions Variables**. Секрет `VEDISMM_TOKEN` уже используется в успешной тестовой публикации; его значение **не записывать в файлы**.
- Прежде проверить workflow в режиме `preview`. После включения `enqueue` ставит 1 одобренный пост.
- Проверять статус публикаций и ошибки ВК. **50 в сутки находится около встречающегося в интеграциях антиспам-предела VK**, точная квота может зависеть от ключа и аккаунта. Не обходить ограничения.

Стартовое число постов до подтверждения качества и платформенных ограничений можно сознательно уменьшить, но целевой планировщик настроен на 50. Без включённого генератора и проверенных рисунков **публиковаться 50 раз в день не будет**.
